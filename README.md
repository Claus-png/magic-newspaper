# Magic Newspaper

Drag-and-drop конструктор внутриигровых газет для **Foundry VTT v14**.  
Мастер верстает — игроки читают в реальном времени.

---

## Что нового в 2.0

### Персонализированные выпуски: теперь это реальность

Газета больше не выглядит одинаково для всех — появилась возможность создавать по-настоящему адресные сообщения.

- **Видимость для избранных** — можно указать, кто именно увидит тот или иной элемент на странице: конкретный игрок, роль или весь стол.
- **Индивидуальные варианты** — альтернативный текст или другое изображение для конкретного игрока или целой роли (например, для всех «Доверенных лиц»). Больше никаких «все видят одно и то же».
- **Режим «Искажённое восприятие»** — триггеры, которые меняют содержимое в зависимости от состояния персонажа (эффекты, флаги). Персонаж с безумием увидит в газете то, чего нет у других — удобно для хоррор-кампаний.

### Техническая перестройка: стабильность и скорость

Движок модуля переработан — визуально незаметно, но ощутимо по стабильности.

- **Умные изображения** — картинки загружаются на сервер как обычные файлы, а не хранятся внутри настроек мира. Добавлена автоматическая миграция старых газет, переделывать их вручную не нужно.
- **Надёжный откат (Undo/Redo)** — история переписана на дельты вместо полных копий страницы, поэтому отмена работает быстрее и стабильнее.
- **Синхронизация через socketlib** — газета открывается именно у того игрока, кому её отправили, а не у всех подряд.

### Редактор: удобство и мощь

- **Слои и порядок** — список всех элементов в панели свойств: закрепление, временное скрытие, быстрое переключение между элементами.
- **Шаблоны** — любую страницу можно сохранить как личный шаблон и отметить избранные пресеты.
- **Безопасность** — перед публикацией модуль проверяет пустые текстовые поля и слишком большие изображения и предупреждает об этом.
- **Горячие клавиши** — быстрый доступ к шаблонам, сохранению черновиков и публикации.

## Возможности

- **9 типов элементов** — шапка, заголовок, текст, изображение, разделитель, цитата, блок, объявление, подпись
- **16 текстур бумаги** — Classic, Gothic, Cyber, Luxury, Noir, Vintage, Art Deco, Tech, Terminal, Grunge, Academic, Archive, Minimal, Industrial, Rustic, Construct
- **Галерея шаблонов** — 6 готовых стартовых макетов (вестник, плакат розыска, секретный документ, киберотчёт, королевский указ, срочный выпуск)
- **Экстренный выпуск** — оверлей поверх интерфейса всех игроков с анимацией и звуком
- **Real-time доставка** — публикация мгновенно отображается у всех клиентов через socket
- **Reveal-механика** — элементы раскрываются по клику игрока
- **Независимая навигация** — каждый игрок листает страницы в своём темпе
- **Кнопка «Показать всем»** — GM принудительно переключает страницу у всех
- **История действий** — Ctrl+Z / Ctrl+Y, до 50 шагов
- **Drag & Drop** — актёры, картинки и записи журнала прямо на холст
- **Автосохранение** — с кнопкой восстановления последней версии
- **Архив и черновики** — управление выпусками
- **Экспорт** — самодостаточный HTML-файл, JSON-бэкап
- **Сохранение в Журнал** — страница газеты попадает в личный журнал игрока
- **Права по ролям** — Create / Edit / Publish / View настраиваются независимо

## Использование

После включения модуля кнопки появляются в двух местах:
- **Боковая панель Notes** (иконка карты) — для GM и игроков
- **Журнал (Journal)** — кнопки «Редактор» и «Газета» в шапке списка

### Быстрый старт

1. Нажмите **Редактор** → откроется конструктор
2. Выберите шаблон через кнопку **Шаблоны** в тулбаре
3. Заполните текст и изображения
4. Нажмите **Выпустить** — игроки получат уведомление в чат

### Горячие клавиши редактора

| Клавиша | Действие |
|---------|----------|
| Ctrl+Z / Ctrl+Y | Отмена / Повтор |
| Ctrl+S | Сохранить |
| Ctrl+D | Дублировать выбранный элемент |
| Ctrl+Shift+T | Открыть галерею шаблонов |
| Ctrl+Shift+S | Сохранить черновик |
| Ctrl+Enter | Опубликовать |
| Alt+1 / 2 / 3 | Переключить вкладку (холст / архив / черновики) |
| Стрелки | Точное позиционирование (Shift = по сетке) |
| F | Подогнать зум под окно |
| G | Переключить сетку |
| Escape | Снять выделение |
| Delete / Backspace | Удалить элемент |

## Известные ограничения

- Google Fonts требуют интернет-соединения; при отсутствии сети шрифты заменятся системными
- Старые газеты с изображениями, сохранёнными как base64, мигрируются в файлы автоматически при первом запуске GM — ручных действий не требуется
